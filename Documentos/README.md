# Documentação do projeto

O [relatório oficial do grupo](Apostila%20de%20Projeto%20-%20Grupo%205.pdf) reúne o planejamento, a implementação e os resultados das etapas do projeto. Esta versão tem 84 páginas e corresponde ao PDF atualizado fornecido pelo grupo em 15/11/2026, exportado do documento oficial no Google Docs.

O documento oficial do grupo é a fonte de edição do relatório. Esta pasta mantém sua versão em PDF; materiais auxiliares de preenchimento e versões intermediárias não fazem parte da entrega.

A documentação técnica para configurar, executar e testar o software permanece nos READMEs das etapas e nos documentos técnicos indicados no [README principal](../README.md).
